# Filas del selector de sesiones

## Objetivo

Cada sesión y la opción de crear una sesión nueva ocupan una sola fila visible y navegable, incluso cuando el texto de vista previa es largo.

## Alcance

El selector conserva el filtrado, el orden, la navegación y el desplazamiento actuales. Las vistas previas largas se recortan al ancho disponible en vez de envolver y desalinear la selección.
