# Start here

**What it is**

Loomcoding is a code agent for the terminal. This page is the entry point of the user guide.

**What it is for**

- Finding the right page quickly.
- Knowing where the first steps are.

**How**

1. Read the [documentation index](../../README.md).
2. Start the program from the folder of your project with `loom`.

## Example

```text
$ cd my-project
$ loom
```
