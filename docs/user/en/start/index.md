# Start here

**What it is**

Loomcoding is a code agent for the terminal. This section takes you from a new profile to a first prompt that gets an answer.

**What it is for**

- Building and checking Loomcoding from source.
- Connecting a cloud provider or a model server on your own machine.
- Sending your first prompt in your own project.

**How**

1. Read the pages in the table below, in order.
2. Each page lists its defaults and says whether a change needs a restart.

## Example

```text
PS> cd <project-folder>
PS> loom
```

## Pages

| Order | Page | What you get |
|---|---|---|
| 1 | [Install Loomcoding](install.md) | A built `loom` binary and a version check |
| 2 | [What happens on the first run](first-run.md) | The files the first start creates |
| 3 | [Connect a cloud provider](cloud-provider.md) | A hosted model reached with an API key |
| 3 | [Run a local model server](local-provider.md) | A model served from your own machine |
| 4 | [Send your first prompt](first-prompt.md) | An answer in your project |
