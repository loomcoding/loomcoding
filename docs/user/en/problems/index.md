# Which page fixes my problem?

**What it is**

This section lists the problems that users meet most often. Each page follows the same pattern: the symptom, its cause and the fix.

**What it is for**

- Finding the page for a message or a behaviour that you see.
- Going from a symptom to a fix you can copy.

**How**

1. Find your symptom in the table below.
2. Open its page and follow the fix for your case.

## Symptoms and pages

| Symptom | Page |
|---|---|
| The model does not answer, or the turn stops early | [Why does the model not answer, or stop early?](no-response-from-the-model.md) |
| `down` or `sin acceso (clave)` next to a server in `/provider` | [Why does a local server show down or no access?](local-server-down.md) |
| A change to a setting has no effect | [Why did my change not apply?](change-did-not-apply.md) |
| The session does not open, or `autenticación local rechazada` appears | [Why can I not open the session?](cannot-open-the-session.md) |
| Tool output starts with `[filtrado: …]`, or lines are missing | [Why does the tool output look filtered?](output-looks-filtered.md) |
| The turn does not finish, or `Necesita tu decisión` appears | [Why does the turn not finish?](turn-wont-finish.md) |
| A tool did not run, or you chose `Denegar` | [Why was my tool denied, and how do I allow it?](tool-was-denied.md) |
