# Título como pregunta o como acción

**Qué es**

Una o dos frases sobre lo que cubre la página. Cada párrafo, como máximo, de cuatro líneas.

**Para qué**

- El primer caso de uso.
- El segundo caso de uso.

**Cómo**

1. El primer paso.
2. El segundo paso.

## Ejemplo

```text
<fragmento de comando o de configuración>
```

## Ajustes y valores por defecto

| Nombre | Valor por defecto | Requiere reiniciar |
|---|---|---|
| `nombre` | `valor` | sí o no |

## Resultado

Lo que se ve cuando funciona, y qué hacer cuando no funciona.
