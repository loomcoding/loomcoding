# ¿Qué página resuelve mi problema?

**Qué es**

Esta sección recoge los problemas que más encuentran las personas usuarias. Cada página sigue el mismo esquema: el síntoma, su causa y la solución.

**Para qué**

- Encontrar la página del mensaje o del comportamiento que ves.
- Pasar de un síntoma a una solución que puedes copiar.

**Cómo**

1. Busca tu síntoma en la tabla de abajo.
2. Abre su página y sigue la solución para tu caso.

## Síntomas y páginas

| Síntoma | Página |
|---|---|
| El modelo no responde, o el turno se detiene pronto | [¿Por qué el modelo no responde, o se detiene pronto?](no-response-from-the-model.md) |
| `down` o `sin acceso (clave)` junto a un servidor en `/provider` | [¿Por qué un servidor local aparece como down o sin acceso?](local-server-down.md) |
| Un cambio en un ajuste no tiene efecto | [¿Por qué no se aplicó mi cambio?](change-did-not-apply.md) |
| La sesión no se abre, o aparece `autenticación local rechazada` | [¿Por qué no puedo abrir la sesión?](cannot-open-the-session.md) |

| El turno no termina, o aparece `Necesita tu decisión` | [¿Por qué el turno no termina?](turn-wont-finish.md) |
