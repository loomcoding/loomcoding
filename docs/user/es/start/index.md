# Empezar aquí

**Qué es**

Loomcoding es un agente de código para la terminal. Esta sección lleva de un perfil nuevo a un primer prompt con respuesta.

**Para qué**

- Compilar Loomcoding desde el código fuente y comprobarlo.
- Conectar un proveedor en la nube o un servidor de modelos en tu propia máquina.
- Enviar tu primer prompt en tu propio proyecto.

**Cómo**

1. Lee las páginas de la tabla siguiente, en orden.
2. Cada página indica sus valores por defecto y si un cambio requiere reiniciar.

## Ejemplo

```text
PS> cd <carpeta-del-proyecto>
PS> loom
```
