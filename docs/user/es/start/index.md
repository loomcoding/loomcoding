# Empezar aquí

**Qué es**

Loomcoding es un agente de código para la terminal. Esta página es la entrada a la guía de usuario.

**Para qué**

- Encontrar rápido la página adecuada.
- Saber dónde están los primeros pasos.

**Cómo**

1. Lee el [índice de la documentación](../../README.md).
2. Arranca el programa desde la carpeta de tu proyecto con `loom`.

## Ejemplo

```text
$ cd mi-proyecto
$ loom
```
